# Tarefa 1.1 — Inicializar projeto React + Vite + TypeScript com estrutura de pastas

## Status: ✅ Concluída

## O que foi feito

- Scaffold do projeto com `create-vite` (template `react-ts`)
- Nome do projeto alterado para `truebarbershop`
- Dependências instaladas via pnpm:
  - `react-router-dom` (roteamento)
  - `@tanstack/react-query` (data-fetching/caching)
  - `@supabase/supabase-js` (cliente Supabase)
  - `tailwindcss` + `@tailwindcss/vite` (estilização)
- Estrutura de pastas criada:

```
src/
├── components/
│   ├── ui/          # Componentes reutilizáveis (botões, inputs, modais)
│   └── layout/      # Layout autenticado, sidebar, bottom-nav
├── contexts/        # React contexts (auth, tenant, etc.)
├── hooks/           # Custom hooks (useTerminologia, etc.)
├── lib/             # Utilitários (supabase client, helpers)
├── pages/           # Páginas/rotas do app
├── routes/          # Definição de rotas
├── services/        # Lógica de domínio (agenda, financeiro, etc.)
├── styles/          # CSS global e tokens
└── types/           # Tipos TypeScript das entidades
```

- `vite.config.ts` configurado com:
  - Plugin do Tailwind
  - Alias `@` → `src/` para imports absolutos
- `tsconfig.app.json` atualizado com paths `@/*`
- Arquivo `.env.example` criado com vars do Supabase
- `src/main.tsx` atualizado para importar `styles/globals.css`
- `src/App.tsx` simplificado com placeholder usando classes Tailwind
