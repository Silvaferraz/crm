# Tarefa 2.7 — Hook useTerminologia()

## Status: ✅ Concluída

## O que foi feito

- `src/lib/terminologia.ts` — sistema de terminologia:
  - `getRotulos()` — retorna todos os rótulos de uma vertical
  - `getRotulo()` — busca único rótulo com fallback: override → vertical → padrão → chave crua
  - `getServicosSugeridos()` — serviços sugeridos por vertical
  - `getIconePorServico()` — mapa de palavras-chave → ícone
- `src/hooks/useTerminologia.ts` — hook que:
  - Pega `categoria` do TenantContext
  - Retorna `{ t(), todos, servicosSugeridos, iconeServico, categoria }`
  - Memoizado por `tenant.categoria`
