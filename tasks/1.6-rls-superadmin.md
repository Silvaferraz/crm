# Tarefa 1.6 — Criar exceção de RLS para super_admin

## Status: ✅ Concluída

## O que foi feito

Implementada no `00002_rls.sql`:

- Função `auth.is_super_admin()` verifica se o usuário autenticado tem `super_admin = true`
- A política `auth.tenant_policy()` já embute a exceção: se `auth.is_super_admin()` retornar true, a política libera acesso a todas as linhas independentemente do `tenant_id`
- Super admin pode atravessar tenants deliberadamente sem "desligar RLS"
- Tabela `despesas_saas` (sem tenant_id) tem política exclusiva para super_admin
